# Конфігурації pretargeting — головна панель управління для більшості покупців Authorized Buyers

**Атомарний факт:** Ви отримуєте рівно 10 конфігурацій pretargeting на місце Google Authorized Buyers.

Все інше (логіка bidder, вибір креативу, обмеження частоти) відбувається після того, як трафік вже надійшов до вас. Pretargeting — єдиний засіб управління обсягом на стороні біржі.

## Що насправді контролює одна конфігурація pretargeting

Кожна конфігурація — це набір правил, що каже Google: «надсилай мені лише запити ставок, що відповідають цим критеріям».

| Поле                 | Ефект                                                                  | Типова помилка |
|----------------------|------------------------------------------------------------------------|----------------|
| **State**            | Active або Suspended                                                   | Залишення мертвих конфігурацій активними |
| **Max QPS**          | Жорстке обмеження запитів на секунду для цього набору правил           | Встановлення занадто високого значення «про всяк випадок» |
| **Geos (included)**  | Країни, регіони, міста (лише грубі сегменти)                          | Покладання лише на широкі «Європа» або «Азія» |
| **Geos (excluded)**  | Явні блокування, що перевизначають включення                           | Недостатньо агресивне використання виключень |
| **Sizes (included)** | Конкретні розміри оголошень або «all»                                  | «All», коли у вас є лише креативи фіксованого розміру |
| **Formats**          | VIDEO, DISPLAY_IMAGE, DISPLAY_HTML, NATIVE                             | Прийняття форматів, для яких у вас немає креативів |
| **Platforms**        | DESKTOP, MOBILE_APP, MOBILE_WEB, CONNECTED_TV                         | Надсилання трафіку мобільних додатків до кампаній лише для десктопу |
| **Publishers**       | Списки дозволених/заборонених для конкретних доменів або пакетів додатків | Управління через незручний цикл завантаження/вивантаження CSV Google |

**Атомарний факт:** Google досі надає лише грубі географічні сегменти (Схід США, Захід США, Європа, Азія тощо). Точний таргетинг на місто або DMA всередині pretargeting недоступний.

## Чому нативний UI незручний

Інтерфейс pretargeting Authorized Buyers вимагає завантаження шаблону CSV, редагування офлайн і повторного завантаження навіть для однорядкової зміни. Немає журналу, немає попереднього перегляду впливу та немає простого відкату.

Саме цю проблему і був створений Cat-Scan для вирішення.

## Безпечний робочий процес змін (що потрібно реальному оператору)

Виробничий робочий процес повинен підтримувати:

1. Редагування в UI (або через API).
2. Сухий запуск / попередній перегляд точної різниці до того, як щось буде надіслано до Google.
3. Підготовку зміни.
4. Запис того, хто що змінив і коли (повний аудит).
5. Відкат в один клік до будь-якого попереднього знімку стану.

Cat-Scan реалізує саме цей процес поверх API Authorized Buyers. Зміни попередньо переглядаються, потім явно застосовуються, потім зберігаються як знімки для миттєвого відкату.

Дивіться повний опис у розділі посібника та реалізацію в платформі.

## 10 конфігурацій — це не багато

Маючи лише десять слотів, ви швидко навчаєтесь бути безжальними:

- Одна-дві «широкі, але безпечні» конфігурації для перевіреного обсягу.
- Кілька вузьких, високоточних конфігурацій для конкретних гео + розмірів + форматів, де у вас є сильне покриття креативами.
- Призупинені конфігурації, що використовуються як майданчики для підготовки перед просуванням.

Все, що активно не виробляє ставок або витрат, займає один з ваших десяти дорогоцінних слотів і повинно бути призупинено або видалено.
