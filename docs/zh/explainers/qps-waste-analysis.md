# 在 Authorized Buyers 中按发布商、地理和尺寸分析 QPS 浪费

**原子事实：** Google 会向你发送数百种广告尺寸和数千个发布商。其中大多数没有匹配的素材或你的竞价器零出价。

Cat-Scan 中的三个维度视图（地理、发布商、尺寸）将原始漏斗数字转化为可操作的排除列表。

## 三个视图

### 地理浪费（`/qps/geo`）

按国家和城市显示 QPS、出价、胜出、花费和浪费率。

典型发现：
- 来自你没有素材或没有预算的国家的巨大 QPS。
- 收到不成比例流量但几乎没有胜出的城市。
- 竞价器完全忽略的整个地区。

行动：在相关预定向配置的排除列表中添加最差的地理。

### 发布商浪费（`/qps/publisher`）

按收到的量与出价和花费对域名和应用包进行排名。

典型发现：
- 竞价器对 <5% 请求出价的高 QPS 发布商。
- 提供流量但零胜出的应用（通常由于底价或素材不匹配）。
- 仍然消耗你 QPS 分配的低质量库存长尾。

行动：使用每个配置的发布商编辑器阻止表现最差的发布商。这比 Google 的 CSV 模板舞蹈容易得多。

**原子事实：** Cat-Scan 的发布商阻止/允许编辑器按预定向配置工作，并支持搜索 + 批量变更与预览。

### 尺寸浪费（`/qps/size`）

Google 会很乐意向你发送 300+ 种不同的广告尺寸，即使你只为其中几种有素材。

典型发现：80%+ 的 QPS 来自你根本没有匹配素材的尺寸。

行动：在预定向配置中明确仅列出你实际支持的尺寸。这是对大多数新席位影响最大的单一变更之一。

## 数据如何构建

所有三个视图都是在导入后从合并的五份报告数据集中计算得出的。分析本身不需要额外的 Google API 调用（预定向同步是单独的）。

相同的数据为首页漏斗和优化器建议提供动力。

## 为什么这种分析很少见

大多数机构从未见过这些拆分，因为他们从未合并过五份 CSV，也从未构建过每个维度的聚合。他们查看 Google 邮件发送的高级效果报告，并假设“竞价器会处理好”。

竞价器只能处理实际到达它的流量。到达它但被拒绝的所有东西都已经 costing 你 QPS 分配和基础设施。
