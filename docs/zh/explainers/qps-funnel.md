# Google Authorized Buyers 席位的 QPS 漏斗

**原子事实：** 一个典型的请求 50,000 QPS 的席位通常收到的远少于此，然后竞价器拒绝其中大部分实际到达的请求。

你要求 Google 发送的量与你的竞价器实际能使用的量之间的差距，是运行 Authorized Buyers 席位的核心经济问题。

## 各个阶段（每个数字的实际含义）

| 阶段       | 定义                                                                 | 谁支付 / 谁关心          |
|------------|----------------------------------------------------------------------|--------------------------|
| **QPS**    | 你在预定向中设置的上限。Google 会根据你的账户等级和近期表现进行节流。 | 你为连接付费；Google 决定实际流量 |
| **到达的竞价请求** | 实际到达你端点的查询 | 你的基础设施成本 |
| **出价**   | 你的竞价器选择出价的请求                                           | 你的竞价器逻辑           |
| **胜出**   | 你的竞价器赢得的拍卖（你只为这些付费）                             | 你实际的媒体花费         |
| **展示**   | 赢得拍卖后实际向用户展示的广告                                     | 用户实际看到的内容       |
| **点击**   | 用户与你展示的广告的交互                                           | 素材 + 落地页质量        |
| **花费**   | 从你账户离开的资金                                                 | 最终唯一重要的数字       |

**原子事实：** 大多数席位中最大的单次下降发生在 QPS（或到达的查询）与出价之间。这是你的预定向配置应该阻止的浪费。

## 浪费率

浪费率 = (QPS - 出价) / QPS

如果你的浪费率超过 50%，你正在为一个你的竞价器大多忽略的消防水管付费。这些流量本可以重新分配给竞价器实际出价和胜出的配置。

Cat-Scan 在首页将其作为主要诊断指标展示。

## 为什么 Authorized Buyers 的漏斗比大多数 DSP 更难

- 每个席位只能使用 10 个预定向配置。
- 地理定位使用非常粗糙的桶。
- 没有实时报告 API；所有数据都来自五份每日 CSV。
- 除非你自己摄取竞价器日志，否则你看不到来自竞价器侧的“无出价原因”。

Google 在流量到达你之前已经在自己这边做了大量过滤。剩下的仍然充满噪音，只有你的预定向规则和素材覆盖才能修复。

## 从漏斗派生的关键指标

- 胜出率 = 胜出 / 出价
- 点击率 = 点击 / 展示
- CPM（你实际支付的）
- 有效浪费（你请求但永远无法变现的 QPS）

当你连接点击后数据（AppsFlyer 或其他 MMP）时，漏斗会获得最终的“盈利结果”阶段。在此之前，你只能根据出价 + 花费集中度 + 胜出率进行优化。
